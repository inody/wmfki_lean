4

設計誤差と残差誤差を別々に証明

設計 D₀ の枝

本物の∇φを使う特徴差を、独立性ではなく依存したL⁴×L⁴ Cauchy–Schwarzで評価。実時間核の可測性・L²性・Fubini条件を先に証明し、iidペア評価とμₜ×μₜ母集団設計へ接続します。

E ‖Aᴺ_cts − A_pop‖F² ≤ C M / N

残差 V₀ の枝

実粒子SDEのItô弱恒等式、Brownian共分散・等長性、時間部分積分から連続弱残差を構成します。残差を抽象的な入力値に置き換えません。

continuous weak residual energy ∝ σ² / N
ActualDesignCoupling.lean · ContinuousPopulationRate.lean · EmpiricalResidualEnergy.lean
5

観測誤差と求積誤差を同じX上で加える

観測誤差は潜在系との独立性だけを要求します。偏りや、粒子・時刻・座標間の依存を許し、観測第4モーメントを要求しません。

D₀ ≤ C_A (1/N + e + q)
V₀ ≤ C_V (σ²/N + e + q)

e = Δt²ᵖ、q = Cε σobs²と読めます。RMS求積精度自体は黄色の明示的仮定です。

ActualObservedDesign.lean · JointWeakBudgets.lean

論文式とproduction定義を同定

新しい連続・離散設計をfullPairDesignへ、実微分を使う応答をobservedWeakResponseへ、差をfullRegressionResidualへ厳密に書き換えます。

ContinuousDesignBridge.lean · DiscreteDesignBridge.lean · WeakResponseBridge.lean
7

ランダムペア抽出を加え、二つの推定法へ

一様有向非対角ペアを復元抽出し、全行・全原子で同じ抽出列を共有します。条件付き中心化からQ/Pを加え、既存のOLS・LASSO回復APIを呼びます。

OLS: ‖θ̂−θ*‖² ≤ 4 V /(ε γ²)
LASSO: ‖θ̂−θ*‖² ≤ 144 |S| λ²/γ⁴

出力 RecoveryCertificate。これは仮定ではなく、幾何・smallness・penalty条件を満たしたときに使用できる証明書です。

重要な量化順序

「各Nごとに都合のよい定数を選ぶ」証明ではありません。先にモデルと共通定数を固定し、その後ですべてのNを扱います。

先に存在

∃ Y, R, Rpos, CA, CV

平均場解と共通モーメント・誤差定数。

その後すべての粒子数

∀ N, 0 < N → ∃ BN, X

同じYと共通定数に対する粒子系。

さらに任意の観測設計

∀ grid, noise, e, q

明示したL²・求積条件の下で同じD₀/V₀形。

対象外

任意の既存joint realizationへの普遍移送、コピーの新しい粒子filtrationへの追加適合性、無限時間一様率、推定量自体の可測性、数値ソルバーの正当性、support回復は含みません。

N=0や退化例は？

率はN>0についてのみです。定義や補題ではN=0,1、T=0、零エネルギーを別途検査し、ゼロ除算を隠していません。

公理0なら全部証明した？

いいえ。公理0は、宣言した定理がプロジェクト固有の仮置き公理に依存しないという意味です。黄色で示したRMS求積・幾何・penalty条件は、定理文に明示された仮定です。
